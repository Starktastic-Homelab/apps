# Utility, download and MQTT retained storage

This is the activation contract for the eight-app cohort; activation is still pending until its reviewed execution receipts and final completion report exist.

Private state moves to static ext4 images under Proxmox owner9999 on`k3s-block`, using the unmodified upstream driver, Retain and ReadWriteOncePod. Sizes are2GiB for qBittorrent and1GiB each for qBittorrent RU, Changedetection, Stirling-PDF, Microbin, Lingarr, Mosquitto and Zigbee2MQTT. PVC names and handles are explicit in `infrastructure/base-configs/templates/utility-home-block-storage/*-bindings.yaml`.

Ordinary Terraform destroy/apply and worker replacement retain the existing workflow: disk identities/bindings/guard bytes come from Git, physical worker retirement supplies fencing, and the generic marker guard (`infrastructure/base-configs/files/retained-startup/guard.py`, ConfigMap `retained-startup-guard`) refuses a volume without its marker before the app starts. Each marker is `.homelab-<app>-data` on the volume root holding exactly `homelab/<app>/data/v1` and a newline (`.homelab-qbittorrent-data`, `.homelab-qbittorrent-ru-data`, `.homelab-changedetection-data`, `.homelab-stirling-pdf-data`, `.homelab-microbin-data`, `.homelab-lingarr-data`, `.homelab-mosquitto-data`, `.homelab-zigbee2mqtt-data`). The guard checks no native files, formats or versions. [Every marker](retained-startup-guard.md) is listed with its guard arguments. No Kubernetes-metadata backup acceptance is added to Terraform. Shared media/download paths and Lingarr's existing PostgreSQL enrollment remain unchanged.

The original NFS sources, their admission holds, the cold ZFS snapshots and the encrypted recovery copies were [retired on 2026-11-16](../../infrastructure/system/proxmox-csi/README.md#retired-migration-sources-2026-11-16). Changedetection later moved to the `changedetection-files` NFS volume ([ordinary-file runbook](ordinary-file-storage.md)), and its block image was retired with them. Recover the current target from backup; never replay stale source state.

Every allocation/growth reserves all active future raw-image growth, remaining cohort images,512MiB staging and8GiB spare against fresh dataset and pool availability. The approved quota ceiling is288GiB for dataset GUID13918781591004512447. The quota change must have its own accepted native receipt; approval alone is not evidence that it was applied. Do not remove a live image to manufacture capacity.

qBittorrent main/RU share an inherited values base, so both must be stopped, backed up, independently restored/qualified and populated before their paired activation PR. Keep every torrent/resume ID, category/tag, counters, settings and VueTorrent cache. Capture the original native API counters first. Through the stock API temporarily select a one-minute resume-save interval, wait until every captured upload/download counter is present on disk, and restore the original interval and all preferences before shutdown, including on failure. Refuse shutdown if that checkpoint/restoration fails. The interval is measured in minutes. Gracefully stop the native s6 service and prove no restart occurred before scaling away the source. Verify the original interval on recovered stock startup and immutable cold counters against the original API before population/authority. Torrent activity and queue settings remain untouched. Payload performance troubleshooting remains a separate task; this migration does not tune it.

Mosquitto's permanent persistence path is`/mosquitto/data/`. The one-time repair must first flush original in-memory state through the source PVC, then shut down gracefully and qualify its native persistence independently. Preserve retained messages and durable sessions; do not publish production device commands. Zigbee2MQTT retains its coordinator, network keys, device IDs and serial/MQTT endpoints; never re-pair or generate a new network to pass acceptance.

Recovery was complete native cold files with POSIX and active SQLite proofs, encrypted on VM300 and the operator workstation with keys kept separately outside Git; those copies and the original sources were [retired on 2026-11-16](../../infrastructure/system/proxmox-csi/README.md#retired-migration-sources-2026-11-16). Finish only after native acceptance, recreation, healthy-worker movement, exact default placement, current-main equality, six clean minutes of normal automation, exact transient cleanup and owner release.
